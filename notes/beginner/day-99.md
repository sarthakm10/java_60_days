# Day 99 — DSA Mock: A Timed Coding Round

> Tomorrow is the full mock interview. Today, rehearse its first round on its own: a timed coding session run exactly like the real thing.

**Today's goal:** solve three problems against the clock, out loud, then review what slowed you down.

## 🧮 Mock — Coding Round (90 min)

Two mediums and a hard in 90 minutes. For each one, follow the same routine out loud: clarify the problem and ask about edge cases → explain your approach and its complexity **before** coding → write clean code → test it by walking through an example → state the final time and space complexity (Days 5 and 14). Interviewers grade your thinking as much as the answer.

## 📝 Day 99 Recap

1. Coding-round routine? → **clarify, explain the approach and complexity, code, test with an example, state complexity**
2. When do you state your approach? → **before writing code**
3. What do interviewers grade besides correctness? → **how clearly you reason and communicate**
4. How should you rehearse? → **a timed mock with a friend, or record yourself**
